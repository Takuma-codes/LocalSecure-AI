# 🛡️ LocalSecure AI - カスタマーハラスメント防衛ダッシュボード

> **クラウド非経由・完全ローカル動作**で、現場の職員を暴言や威圧から守り、心理的負担を軽減する即時防衛システム。

---

## 🌟 主な特徴

1. **🔒 完全ローカル処理（オンプレミス）**
   * 個人情報や相談内容を外部サーバーへ一切送信せず、既存PC内で全処理を完結。漏洩リスクゼロ。
2. **⚡ ハイブリッド2段階検知**
   * **1次判定（爆速）:** キーワード・音量（大声）による即時アラート。
   * **2次判定（文脈解析）:** Qwen2.5 (3B) による丁寧な言葉遣いに隠れた威圧・不当要求の見逃しゼロ検知。
3. **🔊 第三者音声介入（VOICEVOX:ずんだもん）**
   * 暴言検知時にキャラクター音声が自動で割り込み。職員の精神的負担を軽減し、場の空気を一時冷却（マイクミュートによる自声拾い防止機能つき）。
4. **💬 リアルタイムAIカンペ（1.5Bモデル）**
   * 職員がすぐ口に出せる「35文字以内の適切な返答」をリアルタイム生成。
5. **📁 客観的証拠の自動保全**
   * 検知時の音声データとメタデータ（音量・時刻・検知理由）を改ざん不可能な形で自動保存。

---

## 🏗️ 技術スタック・アーキテクチャ

* **GUI:** [Flet](https://flet.dev/) (Python)
* **音声認識 (STT):** [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper) (`small` / CPU-int8)
* **LLM推論:** [Ollama](https://ollama.com/)
  * 判定用モデル: `Qwen2.5:3b`
  * カンペ生成用モデル: `Qwen2.5:1.5b`
  * メモリ最適化: `num_ctx: 1024` 固定による再ロード遅延回避
* **音声合成 (TTS):** VOICEVOX (ずんだもん)
